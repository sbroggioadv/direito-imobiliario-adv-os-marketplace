## Instalação

1. Settings → Plugins → Pessoal → **+**
2. Cole: `https://github.com/sbroggioadv/direito-imobiliario-adv-os-marketplace`
3. Instale `direito-imobiliario-adv-os`
4. `/start-imobiliario` → `/imobiliario-master`
